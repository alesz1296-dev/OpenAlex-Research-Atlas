# Architecture Overview

This project is intentionally small but structured like a platform lab.

## Components

- FastAPI app exposing challenge data
- Docker image for local and CI-based builds
- Kubernetes manifest for local deployment practice
- Terraform code for a minimal AWS networking lab
- GitHub Actions workflow for lightweight CI

## Learning focus

### Kubernetes
- Pods and Deployments
- Services and networking basics
- Readiness and liveness probes
- Local deployment with a simple cluster

### Terraform
- Provider configuration
- Variables and outputs
- Basic AWS resources
- Infrastructure as code structure

### AWS SAA
- VPC and subnets
- Security groups
- Resilience and networking fundamentals
